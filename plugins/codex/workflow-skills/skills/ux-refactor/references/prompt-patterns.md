# Prompt Patterns

## UI Refactor

```text
$ux-refactor on this screen.
Preserve business logic and data flow.
Improve visual hierarchy, spacing rhythm, typography scale, interaction states,
responsive behavior, and accessibility.
Reuse existing components and tokens.
Avoid generic AI-looking UI.
```

## Audit Only

```text
$ux-refactor audit only.
Do not edit files.
Rank UX issues by user impact and propose a safe implementation plan.
Focus on hierarchy, information architecture, spacing, component consistency,
states, accessibility, and responsive behavior.
```

## Tailwind/shadcn

```text
$ux-refactor this Next.js/Tailwind/shadcn screen.
Use local components/ui primitives and existing CSS variables.
Use Button variants for action hierarchy, Badge for status, Skeleton for loading,
Alert for errors, Dialog/Sheet for secondary workflows, and Table/DataTable
patterns for dense operational data.
```

## Stop Generic AI UI

```text
Avoid generic AI UI: no random purple/blue gradients, excessive cards,
glassmorphism, inconsistent shadows, decorative icons without purpose,
low-contrast text, or centered marketing layout for a product workflow.
Use restrained product design with clear hierarchy and semantic color.
```
