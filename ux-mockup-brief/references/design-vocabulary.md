# Vocabulary for observable design choices

Read only the relevant families. These are established concepts and descriptive phrases, not a normative taxonomy or model commands. Translate each selected term into a visible decision with a product reason and a check. Do not prescribe a common style across projects.

| Term | Observable interpretation | Limit or useful check |
|---|---|---|
| Context of use | Adapt to actual attention, environment, device and network conditions. | Label assumptions; do not simulate user evidence. |
| Mental model | Name and group objects in the users' language. | Check understanding of destinations and actions. |
| Information scent | Labels preview what a destination contains. | Avoid clever but ambiguous navigation. |
| Progressive disclosure | Reveal advanced choices when needed. | Keep frequent actions and necessary context accessible. |
| Glanceability | Make current state and next action easy to find. | Do not reduce all information to badges. |
| Information density | Fit comparative information to task and input method. | Avoid tiny type and crowded touch targets. |
| Content-led layout | Let content relationships determine sections and emphasis. | Avoid a fixed hero/cards/testimonials sequence. |
| Asymmetric balance | Balance unequal areas around a dominant content group. | Preserve reading order on small screens. |
| Modular grid | Align related content across reusable columns. | Different tasks may need different compositions. |
| Visual rhythm / negative space | Vary density and breathing room with content sequence. | Do not push essential work out of reach. |
| Microtypography / optical alignment | Refine line breaks, measure, spacing and perceived alignment. | Check real languages, long labels and rendered icons. |
| Tabular numerals | Align comparable numeric data. | Apply where comparison matters. |
| Type-driven / expressive typography | Use typographic composition as an identity element. | Keep controls and reading text comfortable. |
| Art direction / brand personality | Connect composition, type, imagery, tone and motion. | Explain how abstract adjectives become visible. |
| Swiss / International Typographic Style | Structured grid, typographic hierarchy and geometry. | An option, never the default for enterprise software. |
| Editorial | Compose narrative sequences with titles, images and captions. | Adapt when the task is transactional. |
| Humanist typography | Explore open letterforms and a less mechanical character. | Verify actual font readability and language coverage. |
| Neo-brutalism | Strong outlines, flat colors and hard shadows. | Novelty does not prove usability. |
| Analog collage / materiality | Use cuts, textures and material references. | Subject relevance, legibility and asset weight matter. |
| Cinematic / playful | Use framing, rhythm or expressive feedback. | Avoid delaying repeated work or obscuring controls. |
| Restrained palette / semantic color | Assign deliberate roles to color. | Preserve status meanings; minimalism is not mandatory. |
| Purposeful motion | Explain state changes and spatial relationships. | Respect reduced motion and repeated-use efficiency. |
| List-detail / bulk actions | Connect browsing to a selected object or scoped group action. | Preserve selection and make consequences explicit. |
| Adaptive layout / platform conventions | Change presentation for space, input and system behavior. | A narrow web viewport does not validate native UI. |

Examples are conditional: an expert comparison task can justify dense aligned data; a photographic archive can justify an editorial image-led direction; interrupted field work can justify prominent recovery and sync states. These are not industry-to-style mappings.

Sources for selected concepts: [Information scent](https://www.nngroup.com/articles/information-scent/), [Android adaptive design](https://developer.android.com/design/ui/mobile/guides/layout-and-content/adapt-layout?hl=en), [Apple HIG](https://developer.apple.com/design/human-interface-guidelines?lang=en). Consult current official platform guidance when implementing specific behavior.
